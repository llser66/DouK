# DouK 网站交付文档

版本：2026.11.02 · 报送进度与回执体验优化版。适用 Windows 局域网部署。

员工无需注册网站账号，完成抖音账号核验后报送作品。老板登录后查看每日完成数、未完成员工、作品和待审核报送。网站不再自动巡检抖音主页，未完成报送不等于没有发布视频。

- [操作说明](usage.html)：员工报送、多账号核验、回执、每日条数、审核、删除与停用、四项系统设置和常见问题。
- [开发与部署文档](developer.html)：安装启动、局域网、后台接口、数据规则、备份恢复、异地交付和许可。
- [版本验证记录](verification.html)：实际通过的检查、测试证据和仍需现场验收的范围。

## 老板接手先做什么

1. 在运行网站的电脑启动“启动工作台.cmd”，打开 /admin。干净安装首次自动建立 admin / 123456；已有管理员不会被重置。
2. 在部门与人员完善应报员工名册。仅靠首次报送建档，无法发现还未出现过的员工。
3. 在系统设置的报送规则中设置每日条数、执行日、截止时间和生效日期；按需为个人调整。
4. 检查采集连接，用授权的真实作品试报。员工必须至少核验一个抖音账号，免网站登录不等于免核验。
5. 将“访问与备份”里的局域网员工地址发给同网员工；每天查看每日报送进度和报送核查。

## 怎样发给别人

同网员工只需 /report 地址，不必安装。运行后台的电脑须开机、不休眠；老板浏览器可关闭。不能把 127.0.0.1 发给别人的电脑。

不同单位独立安装时发送干净项目交付包，按部署文档安装 Python、Node、Chrome 和项目依赖。数据不会自动互通。不要发送含 Cookie、员工数据、数据库或浏览器资料的个人 data 目录。

本次文档包只包含说明，不含可运行网站或业务数据。Markdown 便于开发者维护；双击 index.html 可离线阅读。服务运行后访问 /help，管理员右上角帮助及员工页底部也有入口。
