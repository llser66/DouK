# 给老板的使用与交接说明

## 老板每天只需要做什么

1. 打开部署网站的电脑，进入安装时使用的 Windows 用户桌面。
2. 双击桌面“DouK 老板工作台”，网页会自动打开；后台没运行时会先尝试启动。
3. 登录管理员账号，查看“数据总览 → 每日报送进度”，跟进差额；在“报送核查”处理待核实和失败记录。

关闭浏览器不会停止后台，老板不必一直保持网站登录。员工可以继续访问。部署电脑关机、休眠或断网时，员工也会打不开。

## 首次交付：请由开发者或部署人员协助一次

目前提供源码交付包，需要先安装环境；它不是完整解压后就能在所有电脑独立运行的免安装软件。

1. 使用 Windows 10/11，在固定目录完整解压，例如 D:\DouK，保留 DouK-Web 和 TikTokDownloader 相邻。不要从 ZIP 内直接双击，不要复制开发电脑的虚拟环境。
2. 安装 Python 3.12+、Node.js 18+ 和 Google Chrome。首次需要联网；Chrome 用于抖音账号核验。
3. 双击 DouK-Web 中“安装环境.cmd”，确认成功；再双击“打开老板工作台.cmd”。首次管理员为 admin / 123456，已有安装的密码不会被重置。
4. 双击“创建老板桌面入口.cmd”。只创建当前 Windows 用户的桌面快捷方式，不自动修改防火墙或创建启动任务。重复创建前会备份旧入口，备份位置会显示。
5. 配置采集连接，使用获得授权的真实账号测试核验、作品识别和报送。设置完整员工名册与每日要求。
6. 在管理员 PowerShell 运行下面的局域网配置；实际网卡名称可在 Windows“网络连接”查看，多网卡时需明确选择：

```powershell
Set-Location D:\DouK\DouK-Web
.\setup-lan.ps1 -InterfaceAlias '以太网'
```

该步骤配置选定网卡、本地子网 TCP 8877 访问，并安排当前 Windows 用户登录时启动后台。不创建无人登录时也能运行的 Windows 系统服务。

7. 在“系统设置 → 访问与备份”复制员工报送网址，在另一台员工电脑测试。地址形如 http://192.168.x.x:8877/report；不要给其他电脑发送 127.0.0.1。
8. 保持部署电脑接通电源、联网和不休眠；建议由网络管理员固定服务器内网 IP。用当前 Windows 用户重启登录后，再确认另一台电脑可以打开报送页面。

首次演示、桌面入口和重启验证完成后，再交给老板日常使用。

## 员工需要安装项目吗

不需要。与部署电脑在可互通的局域网里，打开员工报送网址即可。员工无需网站账号，但仍须完成抖音账号核验。

老板和员工在另一家公司：在他们公司的电脑部署一套，不依赖开发者的电脑；新安装的数据与开发者电脑不会自动同步。源码交付包不包含原数据库、Cookie 和业务配置，需要另行、安全地迁移。不同网络共用同一套系统需单独设计部署，当前版本不提供现成公网方案。

## 桌面入口失效或没有打开

- 项目文件夹被移动或改名：先在新位置重新创建桌面入口；登录启动任务也需由维护人员重新配置，不能只改快捷方式。
- 出现启动提示：截图发给维护人员，日志在 DouK-Web\data\launcher-error.log 和 server-error.log；不要删除 data 试图“重装”。
- 本机能打开、员工打不开：检查部署电脑是否休眠、内网 IP 是否变化、员工网络是否互通及局域网防火墙配置。
- 网站能打开但核验/识别失败：查看采集连接和授权账号状态。平台能力可能随平台更新失效，重装或重启不能保证解决。

## 长期使用更省心的方案

如果希望电脑开机后完全无人登录、员工也能随时访问，建议用办公室专用常开电脑或服务器，由维护人员把后台配置成受监控的系统服务，并处理登录核验浏览器会话。这需要单独部署和验收，当前交付默认是“Windows 登录后启动后台 + 桌面双击打开网页”。

停止服务与数据恢复见 docs/developer.md。重复创建桌面入口的旧文件保存在当前用户 LocalAppData\DouK\ShortcutBackups 的时间戳目录，manifest.json 记录原路径和 SHA256；恢复时将旧 .lnk 复制回记录的原路径。
