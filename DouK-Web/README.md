## 安装与入口

Windows，Python 3.12+，Node.js 18+；扫码核验需要服务器安装 Chrome，直播录制另需 FFmpeg。

1. 保持本文件夹与 TikTokDownloader 相邻；首次运行“安装环境.cmd”。
2. 双击“启动工作台.cmd”，在服务器本机 `http://127.0.0.1:8877/admin` 登录。首次安装自动创建账号 `admin`、密码 `123456`；以后重启不重置已有管理员密码。
3. 配置有效采集连接并测试真实作品。
4. 员工入口为服务器局域网地址的 `/report`，在系统设置的“访问与备份”复制。员工无需创建网站账号，但必须至少核验一个抖音账号；首次报送自动建立部门、小组和人员。
5. 需要开放局域网时，由部署人员按照开发文档运行 `setup-lan.ps1`。仅本地子网业务端口 8877；不提供公网部署。服务器须保持开机、服务运行。

部署好后运行“创建老板桌面入口.cmd”，老板以后双击桌面“DouK 老板工作台”即可尝试启动后台并打开管理页。也可双击项目中的“打开老板工作台.cmd”。项目目录移动后，桌面入口与登录启动任务需要重新配置。源码交付包没有自带 Python/Node/Chrome，不是完全免安装软件。

本机管理员：`http://127.0.0.1:8877/admin`；本机报送：`http://127.0.0.1:8877/report`；本机独立工具：`http://127.0.0.1:8879`。员工设备不要用 127.0.0.1。

## 运行规则

管理员设置每日条数、执行日、截止时间和生效日期，可为员工单独设置常规要求或当日调整。已识别且归属审核通过的作品按发布日、责任人和作品 ID 去重计数；重复报送不加条数，补交昨天的作品归入昨天。待核实和识别失败不算有效完成。人员名册需包含所有应报送员工，才能发现从未报送的人。自动巡检已移除，系统不会自动发现员工未报送的平台作品。

当前报送业务使用 TikTokDownloader 已有的 `/douyin/share`、`/douyin/detail`，不新增平台数据接口，也不依赖上游自带 Web UI。缺失指标不显示成 0；未完成报送不能直接认定员工没有发布。登录账号一致仅证明发布账号一致，不证明原创。旧账号巡检实现仅保留用于历史维护，不再由业务界面或调度器执行。独立工具的既有扩展、评论及下载功能不属于运营业务接口。

系统设置现有四项：报送规则、采集连接、操作日志、访问与备份；采集任务页已移除。报送核查每页 30 条，文案折叠、详情展开，全选只选择当前页。

## 数据、备份和分享

业务库 `data/workspace.sqlite`，工具库 `data/tools/workspace.sqlite`，连接配置在相应 settings.json。网页可创建和下载业务 SQLite 快照，默认每日一份并保留最近 14 份；完整迁移还需配置、工具库等，详见开发文档。恢复务必先停服务并保留当前备份。

给同一局域网员工发访问地址即可。给其他单位独立安装，发送干净交付 ZIP；不要直接发 data、Downloads、浏览器资料、虚拟环境或自己的备份。上游完整源码和 GPLv3 license 随包保留。
